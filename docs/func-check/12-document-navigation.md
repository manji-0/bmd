# ドキュメント遷移

[← 目次](./00-index.md)

ファイルスタックとアンカースタックの動作を段階的に確認します。

## ステップ 1 — 深いリンクチェーン

次の順でリンクを辿り、各段階で `O` / `Esc` の戻り先とステータスを確認してください。

1. [レベル A: 見出し](./01-headings.md)
2. 開いたら [レベル B: リスト](./03-lists.md) へ
3. さらに [レベル C: Mermaid](./10-mermaid.md) へ

| 操作 | 期待結果 |
|------|----------|
| `O` または `Esc`（C 上） | B（リスト）に戻る / ステータス `back → 03-lists.md` 相当 |
| もう一度（B 上） | A（見出し）に戻る |
| もう一度（A 上） | このページ（遷移テスト）に戻る |

`Esc` と `O` は同じ「1 ステップ戻る」です。スタック全体の一括リセットはデフォルトではありません。

## ステップ 2 — アンカー優先

[見出しドキュメントのアンカー](./01-headings.md#ナビゲーション用セクション-b) へジャンプしたあと:

| 操作 | 期待結果 |
|------|----------|
| `O` または `Esc` | ジャンプ前のスクロール位置（このページ内） / ステータス `back → previous position` |
| もう一度 | ファイルスタックがある場合は前のファイルへ |

ファイルスタックとアンカースタックが両方ある場合、アンカーが優先されます。

## ステップ 3 — 繰り返しでルートへ

1. [検索テスト](./09-search-targets.md) を開く
2. [テーブル](./06-tables.md) を開く（2 層目）
3. `Esc`（または `O`）を 2 回 — 1 層ずつ戻り、最初に開いたファイルへ戻ることを確認

## スタック上限

スタックは最大 64 層です。深いネストで上限メッセージがステータスバーに表示されることを確認する場合は、循環リンクを手動で辿ってください（このテスト群では意図的に循環は作っていません）。

## 確認項目

- [ ] 相対パスで別ファイルを開ける
- [ ] `O` / `Esc` で一つ前のファイル／位置に戻れる
- [ ] ステータスに `back → …` が出る
- [ ] アンカージャンプ後も同じキーでスクロール位置に戻れる
- [ ] プリフェッチにより再訪問時の表示が速い（任意）
